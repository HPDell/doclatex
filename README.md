# LaTeX to DOCX compiler

This project aims to make a LaTeX compiler that compile LaTeX source file to Microsoft Word directly.
The design focus on scholar writing only.

Features:

- Parse custom macros in the preamble area and in `.sty` files.
- Support cross reference of figures and tables.
- Turn math formulas to OMML formulas, including the conversions on numbers and alignment.
- Basic support for bibliography.
